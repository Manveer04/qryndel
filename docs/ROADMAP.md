# Roadmap

Planned areas are subject to technical review and community discussion.

- Extend query expressions and diagnostics.
- Add schema validation and clearer type behavior.
- Add safe mutations and transaction support.
- Evaluate aggregation and grouping.
- Review a PostgreSQL adapter.
- Evaluate MongoDB and graph database support.
- Improve portable query diagnostics.
- Add developer tooling and editor integration.

No target dates or compatibility guarantees are attached to these items.
