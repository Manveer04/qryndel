# Governance

## Current Maintainer

Manveer Singh is the original creator and founding maintainer of Qryndel.
The project begins with founder-led maintainership while the community and
public API are still small.

## Maintainer Responsibilities

Maintainers review contributions, protect the project's scope and quality,
keep releases reproducible, respond to security reports, and document material
decisions.

## Contributions And Maintainers

Contributors can earn maintainership through sustained, constructive work,
sound technical judgment, reliable reviews, and familiarity with the project.
New maintainers are invited by existing maintainers after discussion.

## Decisions

Routine fixes can be accepted through normal pull request review. Major changes
to language syntax, semantics, type behavior, portability guarantees, or public
APIs should use the RFC process. Breaking changes require a documented reason,
release-note entry, and migration guidance where practical.

## Disputes

Maintainers should seek a written, technical resolution in the relevant issue
or RFC. The founding maintainer makes the final decision while the project is
small, with the aim of evolving toward a broader maintainer decision process as
the community grows.
